game-ui-proof live demo

Tune your game's UI in the browser before your AI agent builds it.

A Claude Code plugin: the agent draws the HUD, menu or effect over a real screenshot of your game at its real resolution, with a panel of sliders and colour pickers. You tune it and press Save. The values.json it writes is the spec, and a script applies it to Godot or Unity.

Try it

Four previews of a made-up platformer's UI, the kind the agent writes for your game. Hover a value to see what it changes, click the stage to find the values behind a spot, hold Space to compare with the defaults, press Z to zoom, drag the sliders, switch variants and states (← → keys), toggle Reduce Motion. Save copies JSON here. This site is static, so there's no local server to write files: Save copies the tuned values to your clipboard instead and keeps them as the defaults in this browser (the panel says so under the buttons). In your own project, serve.py runs on your machine and Save writes values.json next to the preview.

How it works in your project

  1. You ask Claude for a preview of a UI element. It screenshots that spot in your game and writes a page like these, using your fonts, art and theme values, with every state and a few variants.
  2. You tune it. Every change is saved as a draft the agent can read; Save writes values.json, the approved spec.
  3. A review sheet shows every state of every variant side by side.
  4. The agent builds from the spec: apply_godot.py / apply_uss.py write the values into your theme and script defaults (dry run first). Unreal DataTables are read; writing back is by re-import.

Install

Needs Claude Code, Python ≥ 3.8 with Pillow, and Chrome, Edge or Chromium. In Claude Code:

/plugin marketplace add thomas-ratz/game-ui-proof
/plugin install game-ui-proof@game-ui-proof

Then ask for a preview of something in your game, or run /game-ui-proof:ui-preview health bar. Source, docs and sample projects: github.com/thomas-ratz/game-ui-proof.
